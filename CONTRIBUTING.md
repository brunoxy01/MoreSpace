# Contribuir

1. Faça um fork e crie uma branch para a alteração.
2. Use Windows x64 com .NET Framework 4.8.
3. Execute `./build.ps1` no PowerShell. O script compila e roda as verificações isoladas.
4. Teste a interface em janela estreita e larga. Para capturas públicas, use `--preview-demo`, nunca seus dados pessoais.
5. Abra um pull request explicando o problema, o comportamento final e a validação.

Em mudanças de remoção, preserve a revisão dos caminhos, as verificações imediatamente antes da operação e o tratamento de falhas por item. Não transforme uma falha de Lixeira em exclusão permanente silenciosa. Não registre conteúdos de arquivos ou credenciais.

Relatórios de problema devem incluir versão do +Espaço, versão do Windows, passos para reproduzir e mensagem de erro. Remova nomes pessoais e caminhos sensíveis dos logs e capturas.
